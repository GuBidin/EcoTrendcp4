# Eco•Trend

**Vida sustentável, escolhas conscientes.**

EcoTrend é um site de e-commerce (front-end estático) especializado em produtos sustentáveis nas categorias de moda, beleza, casa e tecnologia. O projeto foi desenvolvido como atividade acadêmica (FIAP Paulista).

🔗 **Acesse o projeto:** [gubidin.github.io/EcoTrendcp4](https://gubidin.github.io/EcoTrendcp4/)

## ✨ Funcionalidades

- Página inicial com carrossel de destaques
- Navegação por categorias (Roupas, Beleza, Casa, Tecnologia)
- Vitrine de produtos com avaliação por "folhas de sustentabilidade"
- Página de categoria com listagem de produtos
- Página de contato
- Layout responsivo (mobile-first)

## 🛠️ Tecnologias utilizadas

- **HTML5** e **CSS3**
- **[Bootstrap 5.3](https://getbootstrap.com/)** — grid, componentes e responsividade
- **[Font Awesome 6](https://fontawesome.com/)** — ícones
- **Google Fonts** — Fraunces, Work Sans e JetBrains Mono
- **Unsplash** — imagens de produtos e banners
- **Google Maps Embed** — localização no rodapé

## 🌐 Deploy (GitHub Pages)

O projeto está publicado via GitHub Pages a partir da branch principal. Como o site fica hospedado em um subdiretório (`/EcoTrendcp4/`), todos os links internos são relativos ao próprio repositório — não usam caminhos absolutos (`/categoria.html`), o que evitaria erros de página não encontrada.

Para publicar atualizações:
1. Faça commit das alterações na branch principal
2. Em **Settings → Pages**, confirme que a branch e a pasta de publicação estão corretas
3. Aguarde alguns minutos para o GitHub Pages atualizar o build
